# Writing

1. Use the requested audience, purpose, tone and format. Read any source or draft with `read_file` before referring to it. If an essential fact is missing, mark it or ask one focused question; use reasonable defaults for routine presentation choices.
2. Draft the complete requested content. Lead with the main point and arrange supporting details in the order the reader needs. Use plain verbs, specific nouns and examples that carry information.
3. Revise for factual fidelity and usefulness. Preserve names, numbers, dates, caveats and intended meaning. Remove filler, inflated claims, repetitive conclusions and generic praise. Match length to the request; concise does not mean incomplete.
4. Check every requested section and material claim. Attribute research; label unresolved assumptions. For revisions, explain consequential changes briefly instead of narrating each edit.

Return prose directly unless a file is requested. Use `write_file` for a saved draft and `read_file` to check the output. DOCX/PDF/PPTX tasks use the documents workflow. Drafting an email or post does not send or publish it.

Read [worked examples](references/examples.md) with `skill_file` when a concrete tool sequence would help.
