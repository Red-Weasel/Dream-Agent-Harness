# Provider marks

Bundled display assets, retrieved 2026-10-08 from provider-owned pages. They
identify sign-in destinations only; they are not Dream branding or authentication
evidence. Provider names and marks belong to their respective owners.

| File | Source and extraction |
|---|---|
| `gemini.svg` | [Google Gemini](https://gemini.google/about/), original colored spark paths, mask and gradient/filter definitions from its visible header wordmark, standalone 65 × 65 viewport. The downloaded monochrome spark was replaced because black was unreadable on Dream's dark background. |
| `claude.svg` | [Claude](https://claude.com/), original orange sunburst path from the visible Claude wordmark; standalone 125 × 125 viewport. |
| `grok.svg` | [Grok](https://grok.com/), the two original `mark` paths in its visible header SVG; standalone 34 × 33 viewport, white current color for the dark surface. |
| `codex.svg` | [OpenAI documentation](https://learn.chatgpt.com/docs), original OpenAI blossom path, white for the dark surface. This is the OpenAI provider mark used on the Codex button, not a separately verified Codex-specific emblem. |

No image generation or redrawing was used for these vectors. SVG wrappers contain
only the selected mark geometry, local SVG definitions, viewport and presentation color; no remote assets,
scripts or provider page CSS. The official Grok download package and some logo
CDNs refused direct downloads; rendered official-page vectors were used instead.
